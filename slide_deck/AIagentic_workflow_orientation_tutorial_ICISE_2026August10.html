Live demo 01 · codebase onboarding

First, let Codex learn
the codebase.

steady-2d-heat-inverse solves a forward heat equation, then infers a spatially varying conductivity through an adjoint gradient and PETSc TAO.

What Codex receivesA clean copy of an unfamiliar repository
What we ask forA working model backed by file evidence
Scale checkRepeat the map on jaxPTPolyPol

Opening prompt · demo 01

Give the agent a question
with an observable finish line.

codex · steady-2d-heat-inverse
Onboard me to this repository as a research collaborator. Independently inspect the source, configuration, and tests; do not rely on prewritten agent notes. Explain the scientific objective; trace the forward → adjoint → optimization data flow; identify the main entry points and test strategy; and flag the first risks I should know about. Cite the files you used. Then create concise AGENTS.md guidance. Do not modify scientific source code.

Switch to the terminal →

Debrief · demo 01

The result is not a tour.
It is a working model.

h(x,y)→forward solve→T
T − Tobs→adjoint solve→λ
∇T · ∇λ→TAO update→h′

ENTRY POINTSforward_solver.py, adjoint_solver.py, tao_solver.py

TEST STRATEGYFinite difference, tangent-linear, and Taylor-remainder gradient checks.

EARLY RISKThe project installs flat modules: use from forward_solver, not a presumed src package.

SCALE CHECKThe same evidence-first map applies to the larger jaxPTPolyPol research stack.

Live demo 02 · paper to Mathematica

Now ask for a verified
scientific artifact.

Cov[Pℓ₁(k), Pℓ₂(k)] ∝ ∫−11 dμ 𝓛ℓ₁(μ) 𝓛ℓ₂(μ) [Pg(k,μ) + 1/ng]2

Target: six independent entries for ℓ ∈ {0, 2, 4}. To match Eq. (B2), absorb 1/ng into P0.

Opening prompt · demo 02

Ask it to derive, build,
run, and compare.

codex · paper-to-mathematica-nb_demo
Treat the PDF as the source of truth; do not inspect existing solution artifacts before deriving. Reproduce Chudaykin–Ivanov (2019), p.45, Eqs. (B1)–(B2), and state the conventions. First create and run a Wolfram verification script that evaluates the exact μ integrals and prints MATCH or MISMATCH for all six independent entries. Only after six matches, compose a reviewer-friendly Mathematica notebook and report the validation command.
